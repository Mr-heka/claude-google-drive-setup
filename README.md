# Google Drive setup

Claude walks you through connecting Google Drive, adding a file to a chat, and the question that makes it quote the exact line and page number. It also shows you how to disconnect.

## Use it

Open `SETUP-PROMPT.md`, copy the text in the box into a new chat in Claude, Claude Code or Codex, and follow along.

## Worth knowing

- **Every plan can connect it.** On the Free plan you can connect one tool, paid plans can connect more. On Team and Enterprise, an owner switches the Google connectors on first.
- **What it reads.** Docs, Sheets, Slides, PDFs, images and Microsoft Office files. From Drive it reads the text only, not pictures inside a document.
- **Disconnect any time.** Customize, then Connectors, click Google Drive, then Disconnect.
- **It is not your lawyer.** Use the quote to find the line, then ask yours.
